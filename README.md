# Rainbow-keyboard
适用于EaglercraftX的手机键盘
# 使用方法
## 控制台
按f12打开开发者工具，点击控制台选项，粘贴Rainbow-keyboard-x.x.x.js里面的代码到控制台，运行代码后就出现键盘
## 启动器实例
打开[craf-launcher启动器项目](https://github.com/Andy-177/Craft-Launcher)，下载带有-inject的html并下载coreX.X.X.zip，解压coreX.X.X.zip并打开core.js，在同目录下新建inject,js，粘贴Rainbow-keyboard-x.x.x.js里面的代码到inject.js，保存inject.js后选择inject.js和core.js，把他们压缩成zip文件，点击`+`，选择刚压缩的zip文件，那个就是游戏实例，添加完会自动运行inject.js的代码
